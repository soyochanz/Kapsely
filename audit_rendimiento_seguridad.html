Auditoría Técnica Kapsely

Análisis Integral de Rendimiento, Seguridad y Experiencia de Usuario

1. Resumen Ejecutivo

Kapsely presenta una arquitectura sólida basada en React Native y Supabase. Sin embargo, para alcanzar el nivel de fluidez de aplicaciones como Instagram, es necesario evolucionar de un modelo de "Carga bajo demanda" a uno de "Anticipación de Datos". Actualmente, el rendimiento se ve limitado por la falta de una capa de caché persistente agresiva y por cuellos de botella en las funciones SQL del servidor.

2. Plan de Acción: Sprints de Implementación

He organizado las mejoras en 3 sprints lógicos para asegurar estabilidad y resultados visibles inmediatos.

1
Cimientos: Seguridad y Optimización SQL
Eliminación de vulnerabilidades críticas y aceleración del motor de datos.
Seguridad SQL Backend
  • Sustituir parámetros p_user_id por auth.uid() en todos los RPCs.
  • Refactorizar get_combined_feed_data usando LATERAL JOIN para eliminar subconsultas lentas.
  • Unificar stickers y items en el RPC del Perfil para evitar peticiones múltiples.
2
La Experiencia "Instagram": Caché y Persistencia
Implementación de carga instantánea mediante datos cacheados y sincronización offline.
React Query SWR AsyncStorage
  • Configurar TanStack Query con persistencia en el almacenamiento local del teléfono.
  • Implementar lógica "Stale-While-Revalidate" en el Feed y el Perfil (datos antiguos al abrir, refresco en background).
  • Optimistic UI: Los likes y comentarios se reflejan en la UI en 0ms.
3
Pulido de Medios y UX Visual
Optimización de carga de imágenes y fluidez en la navegación de contenido.
Media Blurhash Prefetch
  • Integración de blurhash en las miniaturas del feed para evitar huecos en blanco.
  • Prefetching de imágenes de cápsulas cuando el usuario desplaza el feed.
  • Uso de transformaciones de Supabase para descargar tamaños optimizados según el dispositivo.
